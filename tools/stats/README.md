# Приёмник анонимной статистики

Веб-приложение Google Apps Script в аккаунте автора. Принимает сообщения программы (`program/Stats.cs`) и складывает их
в Google-таблицу. Ставит его автор сам, один раз.

## Установка

1. Создать новую Google-таблицу (название любое, например «MSS statistics»). Доступ — только себе.
2. В ней: «Расширения» → «Apps Script». Удалить всё из `Code.gs`, вставить содержимое [Code.gs](Code.gs), сохранить.
3. Вверху выбрать функцию `setup` и нажать «Выполнить». Google спросит разрешения (доступ к этой таблице и запуск
   по расписанию) — разрешить. Появится лист `data` с заголовком и ежедневная уборка строк старше 12 месяцев.
4. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»: «Запуск от имени» — «От моего имени»,
   «У кого есть доступ» — «Все». Развернуть и скопировать адрес (кончается на `/exec`).
5. Адрес вписать в `program/Stats.cs`, константа `Url`. Пока она пустая, программа ничего не спрашивает и не отправляет.

Адрес не секрет: по нему можно только добавить строку, прочитать ничего нельзя. Секретов в репозитории нет.

## Что в таблице

Одна строка на сообщение: день получения (без времени), номер установки, версии программы и аддона, старшая версия
Windows, язык программы и игры, режим, вилка числа персонажей, есть ли Mapzeroth, день счётчиков и сами счётчики (JSON).
IP отправителя скрипт не видит. Поля проверяются по шаблонам; что не подошло — остаётся пустым.

## Изменили скрипт

«Управление развёртываниями» → карандаш → «Версия: новая» → «Развернуть»: адрес остаётся прежним.
