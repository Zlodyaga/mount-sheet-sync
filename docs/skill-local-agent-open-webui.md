## Режим C: поиск в интернете через Open WebUI (проверено 16.11.2026)

- Open WebUI — в Docker (контейнер `open-webui`, `http://localhost:3000`, версия 0.13). Нужен запущенный Docker Desktop.
  API без входа отвечает 401, поэтому запрос идёт через его страницу в Chrome Димы (Claude in Chrome): новый чат, в
  меню «+» включена «Поисковая система», модель `qwen-27b-q6-32k` (или `qwen-27b-32k`).
- Умеет: искать (`search_web`) и читать страницы текстом (`fetch_url`). Честно пишет, что не нашёл, и не выдумывает
  адреса, если это прямо попросить. Отвечает по-английски, если вопрос по-английски.
- **Не видит картинок на страницах**: `fetch_url` отдаёт только текст, без `<img>` и их адресов. Поэтому отбирать
  изображения (карты, скриншоты) он не может — только находить страницы, где они, по словам текста, есть.
- Время: 16 поисков и 16 страниц — около 20 минут. Модель занимает почти всю видеопамять: спросить Диму, не играет ли он.
- Когда окупается: широкий поиск по многим сайтам, где Claude потратил бы много запросов, а ответ — короткий список
  ссылок. Проверять результат самому: открыть 2–3 ссылки (`curl` и поиск в исходнике, `get_page_text`), а не верить
  пересказу.
- Ответ длинный — читать его через `get_page_text` вкладки чата, после ответа вкладку закрыть.
- Пример (16.11.2026): карты маршрутов Алани, Холона, Кусачего Ветра, Посейдуса — нашёл 13 источников, карт с линией
  нет ни одной; итог совпал с ручной проверкой.
