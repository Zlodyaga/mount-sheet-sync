# Рары на карте: кому это нужно и что удалось найти (16.11.2026)

Исследование перед тем, как рисовать раров поверх карты мира. Ничего из этого в аддоне ещё нет.

## Откуда данные

- **Wowhead, карта на странице НИП** (`g_mapperData` в исходнике страницы) — точки, где игроки видели существо, сразу с
  номером карты игры (`uiMapId`). Для стоящего рара это места появления, для летающего — облако точек вдоль маршрута.
  Собирает `python3 tools/catalog/rares/spawn_points.py <номера существ>` → `tools/catalog/rares/spawn_points.json`
  (35 существ, собрано 16.11.2026).
- **Warcraft Wiki** — где есть, точные места появления с названиями и (один раз) готовый маршрут по точкам.
- Данные Mount Route Planner не берём: лицензия «All Rights Reserved».
- Картинки с маршрутами (вики: `File:Timelostprotodrakepaths.jpg`, `File:Spawnspotsv2move.jpg`) — только для глаз,
  координаты из них не снять.

## Бесполезно: рисовать нечего

- Рары с одной известной точкой и откатом добычи раз в день (Аргус, Мехагон, Малдраксус, Ревендрет, Кортия, Ульдум и
  Дол времён Н'Зота, Нижняя Шахта…) — точка уже есть в каталоге, Ctrl + щелчок ставит метку.
- «Любой редкий монстр зоны» (Midnight, Запретный край) и четвёрка Танаана — их много, появляются часто.
- «Обычные мобы зоны» (Друствар, Назмир, Долина Штормов, Вол'дун) и бойцы Театра Боли.
- Призываемые: Служитель глубин, Вел'иккан, Гирукон, Скрытень со Дна, Ночная кобыла.

## Вывод

- **Значки мест появления** можно сделать для всего списка «важно», кроме фигурки верблюда. Для шести раров точки
  готовы (вики), для остальных облака Wowhead надо свести в места появления (соседние точки — одно место) и хотя бы
  часть проверить в игре.
- **Линии маршрута** честно рисуются только для Павшего боевого коня. Для летающих (протодракон, Алани, Холон,
  Кусачий Ветер) вместо линии — облако точек наблюдений: оно показывает, где летает, и не врёт о порядке.
- **Не хватает**: фигурки верблюда (≈50 мест), точек Кириев у Павшего коня, проверки, сколько настоящих мест у Посейдуса
  и раров Дренора. Источники, которые стоит посмотреть руками: руководства Wowhead «Mystery in the Shifting Sands: A Grey
  Riding Camel Guide», «In the Depths of Vashj'ir: A Poseidus Guide», «Rare Mounts in Draenor» (их текст автоматически
  не читается), аддоны с открытой лицензией (HandyNotes-модули, RareScanner — лицензию проверить перед тем, как брать данные).

## Поправка 16.11.2026

Первый поиск шёл только по тексту страниц. Карты маршрутов, нарисованные игроками, находятся поиском по картинкам:
пользователь сразу нашёл две для протодракона. Набросок по точкам Wowhead совпал с настоящими маршрутами в одном случае
из четырёх, поэтому вывод выше «линии честно рисуются только для Павшего коня» относится к точкам без карт, а не к тому,
что данных нет. Что делать дальше — `docs/TODO.md`, раздел «Маршруты раров на карте мира».
