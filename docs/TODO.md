- [ ] **Лишний персонаж «Осталось попыт…» слева и столбец «Ост».** Причина найдена: при одном персонаже `WorldLeftFormula` даёт `(pa=FALSE)` без сложения, поэтому в колонке «Осталось попыток выбить» стоят TRUE/FALSE. `SheetLogic.IsCharacterColumn` принимает колонку из одних галочек за персонажа. Поправить проверку (персонажи — только правее `WorldFirstCharColumn`), чтобы вылечились и готовые таблицы, и саму формулу (`N(…)`). Добавить тест на таблицу с одним персонажем. Из-за этой ошибки ещё и неверно «персонажей в таблице: 2», а рар считается ему лишний раз.
- [ ] **Пустые значки у части строк** (Сартарион, Король Мехагон, «Слава герою», «Мастер ключей»…). Причина найдена: значок берётся из `ns.ItemAttempts`, а её индекс строится только из строк с шансом 0 < p < 1. У гарантированных маунтов и достижений ID нет, хотя в `catalog.json` ID есть у всех строк. Нужно передавать `id` в каждой строке статуса (`SheetLogic`) и брать его в аддоне первым. Нужна свежая программа, поднять `MIN_PROGRAM` или оставить пустую рамку как запасной вариант.
- [ ] **Квадратик вместо стрелки: «Мифик ключей □ Затерянное во времени седло».** Причина найдена: в `catalog.json` 38 стрелок «→», а в шрифтах их нет. Заменить в каталоге и при показе в аддоне (`Safe`): в готовых таблицах стрелки уже записаны. Распространить проверку `test_locale.py` на каталог.
