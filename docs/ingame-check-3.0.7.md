# Проверка в игре перед выпуском аддона 3.0.7 и программы 2.10.2

Короткий порядок на 20–30 минут: сначала то, что проверяется где угодно, потом по зонам — чтобы не летать туда-сюда.
Перед началом: **полностью перезапустить игру** (в 3.0.7 новые файлы аддона — `Map.lua`, `Routes.lua`, `Tips.lua`,
`UI.Edit.lua`; `/reload` их не подхватит). Программа — тестовая сборка 2.10.2, лучше на **копии** таблицы Google
(вид таблицы меняется на 7). Подробный список по всем версиям — `docs/ingame-check.md`.

Отметить: ✅ работает, ❌ нет (что видно), ➖ не проверял.

| 1.5 | Совет в подсказке строки (например, Галливикс или любой рейд Legion) | по-русски, без «Mythic-only», «Achievement-run», «скип» | |
