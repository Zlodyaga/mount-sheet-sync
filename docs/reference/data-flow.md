# Как ходят данные

```
WoW (аддон) ──SavedVariables\MountSheetSync.lua──► программа ──Sheets API / Code.gs──► Google-таблица
     ▲                                                │
     ├──────────── SheetData.lua («Осталось», попытки) ┤
     └──────────── Program.lua («программа запущена») ─┘
```

В режиме «на этом компьютере» (`settings.mode = local`, с 2.10.0 у новых игроков по умолчанию) вместо Google-таблицы — файл `local-data.json`: те же листы и строки,
запросов в сеть нет, остальное в этой схеме так же.

`Program.lua` несёт `storage` (`settings.mode`): `local` — аддон пишет «список» вместо «таблицы» (`ns.UsesListWords`, тексты `LIST_WORDS` в `Locales.lua`); программы до 2.10 поля не пишут, у них таблица есть всегда. Нет `Program.lua` — тоже «список».

`SheetData.lua` несёт `names = { ru, en, de, fr, es, pt }` (программа 2.10.0, `SheetData.Names`): переводы маунтов, боссов, мест и названий достижений из таблиц игры (`tools/catalog/game_names.py` → `game_names.json` → `sheet-i18n.json` → `names`), английские ещё и из каталога, ключ — текст строки, только то, что есть в списке. Аддон берёт их, когда его язык не совпадает с языком игры (`ns.Shown`). У строки-награды — `ach`, номер достижения, за которое дают маунт (73 из 82 наград; у сундуков и маунтов за седло его нет).

В `properties` файла данных `skippedCharacters` — персонажи, которых игрок убрал сам (имена через перевод строки).

`local-data.json`: `{format: 1, app, lang, title, properties{}, sheets[{name, id, formulas[], rows[[…]]}]}`. Листы и заголовки — «русские», как в памяти программы (`SheetLang`), значения — на языке данных. Запись атомарная (`.tmp`, затем замена), прошлая версия — `.bak`. Если основной файл повреждён, `LocalBook.Load` откладывает его как `.damaged` и восстанавливает `.bak`, чтобы следующая запись не затёрла копию.

- **Игра → программа.** Аддон пишет `MountSheetSyncDB` в SavedVariables; игра сохраняет файл только при выходе
  на выбор персонажа, выходе из игры и `/reload` («Отправить в таблицу» = `/reload`). Программа видит изменение
  за ≤5 с. Аддоны WoW в сеть не выходят — по-другому никак.
- **Программа → таблица.** Записи, которых нет в `sent-ids…txt`, по 40 за запрос; ответ на каждую — статус
  (`marked`, `already`, `stale`, `not_found`, `wrong_difficulty`, `no_sheet`, `collected`, `planned`, `reset`) и
  попытки.
- **Таблица → игра.** `status` → `SheetData.lua` (`MountSheetSyncSheet`: `generated`, `version`, `spreadsheet`,
  `known` (ID сложностей), `resetAt`, `chars[{name, keys, items[]}]` (у каждой строки `id` — ID маунта для значка, `src = "reward"` — не за убийство босса, `je`, `im` — journalEncounterID и mapID места из каталога для путеводителя, с 2.10.0; у строки с раздельными сохранениями — `sep`, убитые сложности — `k`: «N,M»), `mounts[]` (`id` — из скрытой колонки листа, иначе из каталога: на «Мировых боссах» колонки нет); у строк `items`/`mounts` с 2.9.1 —
  `e` = номера боёв, `Encounters.IdsFor`: аддон 3.0.2 узнаёт убийство по `encounterID`, даже если имя другое) в папку аддона каждой найденной
  игры (`Interface\AddOns\MountSheetSync`). Игра читает его при входе и `/reload`; убитое после `generated` аддон
  отмечает сам по своему журналу.
- **«Программа запущена».** `Program.lua` раз в минуту; аддон считает программу запущенной, если отметка не
  старше 150 с на момент загрузки интерфейса (`ns.ProgramState`: online / nosheet / offline).
- **Атлас и коллекция.** Аддон кладёт в SavedVariables снимок коллекции маунтов и имён Атласа приключений;
  программа берёт из них названия «как в игре» и номера боёв (`GameData.Read`, `Encounters.Use`).
- **Статистика убийств (2.9).** `chars[…].stats` каждого персонажа → `GameCharacter.Stats` (из нескольких файлов
  SavedVariables — с самым свежим `statsAt`) → «Попыток» при сверке с коллекцией.

Запросы к Google на одно действие сейчас: загрузка таблицы (`GoogleBook.Load`) = 3 чтения (метаданные +
значения + формулы), одна на проход цикла (`ping`, `kills`, `status` и сверка берут её из памяти) — отправка убийств со
списком = 3 чтения и 1–2 записи, только список = 3 чтения.

В `SheetData.lua` у строк нет `sheet` и `row`: они есть в ответе таблицы, но аддон их не читает (`SheetData.NotForAddon`).

Рары в `SheetData.lua`: `items`/`mounts` с `kind = "rare"`, у `items` ещё `every` (`"daily"`, `"weekly"` или секунды). Лимит проекта — 300 чтений и 300 записей в минуту (см. [decisions.md](decisions.md)).
