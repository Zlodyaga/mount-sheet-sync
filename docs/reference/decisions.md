# Решения и ограничения

Коротко: что решили и почему, чтобы не обсуждать заново.

- **Программа на C# 5 / .NET 4.8 без зависимостей** — компилятор есть в каждой Windows, исходники рядом с exe,
  любой может собрать сам (`build.cmd`).
- **Таблица программы через Google (drive.file) — основной режим**, скрипт Code.gs (как в 1.x) — запасной.
  Права `drive.file` не чувствительные: без проверки Google, без лимита 100 пользователей, без экрана
  «приложение не проверено». Скрипт-режим масштабируется без общей квоты, но ставится сложнее (копия, развёртывание,
  предупреждение Google для своего скрипта) и не умеет новое с 2.x. Идея на будущее, если квоты не хватит:
  шаблон таблицы со скриптом-посредником (только чтение/запись ячеек), а логика остаётся в программе.
- **Квота 300 чтений/мин на проект.** С 2.9.2 — 3 чтения на отправку убийств со списком (было 6): таблица загружается
  один раз на проход цикла. Метаданные не кешируем между проходами: в них `lastWeekReset` и версия вида, устаревшие
  привели бы к лишнему сбросу. Список читает только обычные ячейки, поэтому таблица из памяти после записи ему подходит.
  Дальше по порядку: попросить увеличение квоты (бесплатно), включить оповещение о 80 % квоты, при росте —
  скрипт-посредник. Делить пользователей по нескольким проектам Google не будем (похоже на обход правил).
- **«Осталось» по расписанию — только пока запущена игра** (2.8) — меньше запросов.
- **«Сброс недели» делает программа сама** (2.9.2). Кнопку забывали, и список врал; нового смысла у сброса нет — те же
  действия, что после кнопки, включая повторную отметку убийств этой недели. Настройки «выключить» нет: сброс недели игры
  не зависит от желания игрока, а ручные «Да» в таблице кнопка стирала так же. Кнопка осталась (программа не запущена, повтор).
- **Рары — без колонок персонажей** (2.9.2). Откат у каждого рара свой и короче недели: галочки пришлось бы чистить по
  разным расписаниям, а дату на персонажа — добавлять при каждом новом персонаже. У аддона уже есть время и персонаж каждого
  убийства (журнал 21 день), поэтому считает он. Цена: убийства на другом аккаунте игры он не видит. Запись из игры остаётся
  `kind = world`, откат берётся из «Сброс / частота». Кнопка «Сброс недели» ушла в настройки: её делает программа.
- **Рар без статистики**: у Исхака и других раров нет статистики убийств, поэтому убийства до установки аддона не
  подтягиваются — «Попыток» начинается с 0. Счёт идёт с добычи. Настоящие данные 31.10.2026: запись `D-…` дошла, попытка
  засчитана; потерять её можно было только при смене цели перед добычей — с 3.0.3 имя запоминается заранее.
- **Окно 3.0: персонажи слева, списки на ScrollBox.** У игроков бывает 20+ персонажей: прежнее окно делало по
  FontString и кнопке на каждую строку (сотни кадров при открытии), ScrollBox делает кадры только для видимых строк
  и переиспользует их. Списки пересобираются по ключу данных, а не на каждый `Refresh`. Данные других персонажей —
  те же `chars[]` из `SheetData.lua` (программу менять не пришлось); «Не фармлю» — только для текущего персонажа
  (запись `P-…` пишется от его имени). «Не писать в чат» и «Очистить журнал» ушли в настройки: ими пользуются
  редко, а место внизу окна нужно частым действиям. Мажорная версия — потому что окно другое целиком.
- **Локальная модель (gpt-oss:20b) для кода аддона не годится** (проверено на 3.0, 30.10.2026): готовый фрагмент
  вставляет с правками или по нескольку раз, теряет кавычки. Справилась только с маленькой функцией по описанию
  (`ns.GetAttemptsList`), и ту пришлось переделать ради скорости. Большие правки окна — не ей.
- **Счётчик попыток — в таблице**, общий на всех персонажей; аддон досчитывает неотправленное сам. Повторы после
  «Сброса недели» помечаются `again` и не считаются.
- **Оформление ячеек готовой таблицы — `updateCells` по ячейкам, не `repeatCell`**: repeatCell пропускает строки,
  скрытые фильтром листа (проверено на настоящей таблице 28.10.2026). Новая таблица оформляется до фильтра — там
  всё равно.
- **История попыток — из статистики игры** (2.9, как у Rarity): игра хранит убийства боссов по персонажам. Берём
  max(ячейка, сумма) — без двойного счёта и без отката ручных правок. Список статистик — свой, из данных игры
  (wago.tools, таблица Achievement), сверен с Rarity по совпадающим; Rarity (GPL) не копируем. Статистику со
  «всеми сложностями» для маунта одной сложности не берём — лучше недосчитать, чем приписать лишнее.
- **Убийство узнаётся по номеру боя** (аддон 3.0.2, программа 2.9.1): Blizzard пишет имена по-разному (бой 1563 —
  «Галеон», в Атласе/каталоге было «Галлеон»), имя — запасной путь.
- **Без «·» и стрелок в текстах аддона** (3.0.1): русский клиент рисует их квадратиком (30.10.2026). Разделитель — «-»,
  стрелка — «>»; `test_locale.py` не пускает их обратно.
- **Подсказка юнита — только у раров** (3.0): в рейдах и подземельях игра прячет имена НИП даже до боя, и юнит из
  подсказки не получить — у боссов подсказка не работала; боссы — только значок в Атласе приключений.
- **Рары считаем по добыче**: у них нет ENCOUNTER_END/BOSS_KILL и сохранений, поэтому попытка — открытая
  добыча с трупа (как у Rarity). Нужен список из таблицы программы 2.8+: без него аддон не знает, какие рары важны.
- **Без телеметрии и своих серверов.** Программа говорит только с Google и (раз в сутки) с GitHub API.
  «Сведения для отчёта об ошибке» — текст, который пользователь копирует сам, без имён и таблицы.
- **Подсказки об установке программы** в аддоне — только в пустой «Осталось» и в `/mss left` (правила Blizzard и
  CurseForge, без спама).
- **Ссылки на скачивание** — только сайт (правило CurseForge). Сайт отдаёт exe напрямую: программа сама себе
  установщик, аддон — из CurseForge или из полного архива GitHub.
- **Программа и аддон выходят отдельно** (с 2.8.0): правка программы не тащит «новый» аддон в CurseForge и
  наоборот. Цена — у пользователя могут разойтись версии; на это `MinAddon` / `MIN_PROGRAM` и мягкие подсказки.
  Выпуск — кнопкой в Actions, а не через Releases (иначе у аддона появлялся бы выпуск GitHub без exe).
- **Пробные версии** — теги `-alphaN`/`-betaN`: пре-релиз, на них обновляются только желающие.
- **Логотип в бренде Google убран** — с ним требовалось подтверждение бренда, а сайт на `github.io` Google не
  признаёт «своим доменом». Ответ Google 27.10.2026: страница и политика должны быть на своём подтверждённом домене.
  Тратить деньги на домен не стали: логотип убран окончательно (27.10.2026), Google попросили закрыть заявку.
  Захочется логотип — домен (~$10–15/год, или бесплатный `*.eu.org` без гарантии), перенос сайта, ответ на письмо.
- **exe без подписи** — SignPath Foundation (бесплатная подпись для open source) отказал 27.10.2026: проект пока
  мал. Шаги подписи в release.yml оставлены на будущее (заявку можно подать снова, когда будет больше
  пользователей и звёзд); платный сертификат не покупаем.
- **Безопасность при работе с пользователем**: пароли, ключи и токены вводит он сам (CF_API_KEY, SignPath — в
  секретах GitHub); выпуски и теги создаёт он; соглашения на сайтах не принимаем за него.
- **Окно 1060×600, таблицы вместо строк-предложений** (аддон 3.0.3): числа в одном столбце сравниваются взглядом, длинное название больше не обрезает попытки и шанс. На 1920×1080 при стандартном масштабе экран — около 1365×768 единиц, так что окно занимает 78 % по обеим сторонам; шире не пошли. По каталогу при ~6 единицах на букву целиком влезает 90–95 % маунтов и 80–85 % боссов; остальное — в подсказке. Прокрутка столбцов сетки — сдвигом на персонажа, а не кадром с обрезкой: кадров строк столько же, данные не перестраиваются.
- **Сетка всех персонажей — и с прокруткой, и без** (аддон 3.0.3): по умолчанию широкие столбцы с прокруткой (выбор пользователя), «все столбцы сразу» — в настройках для 15+ персонажей.
- **Раздельные сохранения — только у строк `Normal/Heroic/Mythic`** (программа 2.9.2, аддон 3.0.3): все такие строки каталога — рейды Legion и новее, где у каждой сложности своё сохранение. В рейдах Cataclysm и MoP (`Normal/Heroic`) сохранение считаем общим, подземелья не трогаем. Строку не дробим и «Да» не меняем по смыслу: убитые сложности лежат в скрытой колонке `N/H/M`, поэтому формулы и «Сводка» работают как раньше.
- **Своё оформление окон вместо шаблонов Blizzard** (аддон 3.0.3): в игре окно выглядело тусклее согласованного макета из-за мраморного фона, кнопок и шрифта игры. Страницу браузера в WoW показать нельзя, но кадры, текстуры и шрифты могут быть своими. Цена — окно не похоже на родное, внешний вид поддерживаем сами, аддон вырос примерно на 1 МБ (в архиве вдвое меньше).
- **Шрифты лежат без изменений**: у PT Sans в лицензии (SIL OFL) зарезервированное имя, изменённую копию (например, только с нужными буквами) пришлось бы переименовывать. Лицензии — `Media/OFL-*.txt`. Шрифты из Google Fonts: `ofl/ptsans`, `ofl/philosopher`.
- **ID маунта мировых боссов — из каталога**: на листе «Мировые боссы» скрытой колонки нет, добавлять её ради значка незачем (колонки персонажей идут сразу за «Источником»); `StatusMounts` находит ID через `MountIndex`, если колонки нет.
