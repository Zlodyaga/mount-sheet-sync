# Программа в трее (MountSheetSync.exe)

Windows 10/11, C# 5 под .NET Framework 4.8 (встроенный в Windows компилятор `csc`, никаких пакетов), один exe.
Исходники — `program/`, сборка — `program/build.cmd` (выпуск — `tools/build_exe.ps1` в GitHub Actions),
тестовая сборка под mono — `tools/build_test_exe.sh` (`-define:TESTS` включает тестовые хуки, в выпуск они не входят).

## Режимы

| Режим (`settings.mode`) | Как пишет в таблицу | Что умеет |
| --- | --- | --- |
| Google (по умолчанию, `GoogleSheetService`) | Sheets API от имени пользователя, OAuth | создаёт таблицу на 6 языках, всё ниже |
| Скрипт (`webAppUrl` + `secret`) | POST в веб-приложение Code.gs (`script/Code.gs`, способ 1.x) | только отметки и «Осталось»; нет создания, персонажей, сверки, счётчика попыток |

Вход Google: браузер + локальный порт (loopback), права `drive.file` (только файлы, созданные программой),
`openid`, `email`. Ключ входа — `%APPDATA%\MountSheetSync\google-token.dat` (DPAPI, только этот пользователь
Windows). «Выйти» удаляет ключ и отзывает его у Google.

## Окна

![Настройки](../screens/program-settings.png)

- **Настройки** (`SettingsForm`): режим (таблица программы / своя со скриптом), вход и выход Google, «Создать
  таблицу…», «Персонажи…», «Открыть», папка игры (ищется сама), «Запускать вместе с Windows»,
  «Проверить связь», «Сохранить». Вход и новая таблица сохраняются сразу (`CommitGoogle`).
- **Создать таблицу / Персонажи в таблице** (`GoogleForms.cs`): персонажи из игры с галочками «Рейды»,
  «Подземелья», «Мир. боссы», название, **язык таблицы** (6; по умолчанию язык игры). Изменение персонажей
  показывает, что удалится, перед удалением.
- **Что фармить…** (`FarmForm.cs`): галочки «Фармлю» по дополнениям / рейдам / подземельям на персонажа.

## Цикл синхронизации (`SyncWorker`)

- Каждые `pollSeconds` (5 с) смотрит файлы сохранений `WTF\Account\*\SavedVariables\MountSheetSync.lua`
  всех найденных `_retail_`; папки игры пересканирует раз в 10 мин.
- Новые записи → `SyncEngine.SyncAll`: пакеты по 40 (`BatchSize`), «Сброс недели» — первым, за ним заново все
  убийства той же недели (повторы помечены `again: true`, попыткой второй раз не считаются).
  Отправленные id — `sent-ids-google-<id таблицы>.txt` (у скрипта — `sent-ids.txt`).
- Ошибки Google 429/5xx — повтор через 1, 2, 4, 8 с; дальше — следующая попытка через `retrySeconds` (60 с)
  и раньше, если файл игры изменился (не чаще 30 с) или вернулась сеть.
- Список «Осталось» (`action: status`) → `SheetData.lua` во все папки аддона: после отправки, по «Отправить
  сейчас», и по расписанию раз в 30 мин **только пока запущена игра** (`GameProcess.Running`: Wow, WowT, WowB,
  `-ARM64`), и сразу при её запуске. Под TESTS `MSS_WOW_RUNNING=0/1`, по умолчанию «запущена».
- Если `SheetData.lua` заменил кто-то другой (приложение CurseForge, ставя новую версию аддона, кладёт пустой) —
  программа замечает по времени изменения файла (`KeepSheetFiles`, каждый проход цикла) и сразу пишет список снова.
- `Program.lua` (`ProgramMark`): раз в минуту `seen = <unix time>`, `sheet = <настроена ли таблица>`; при выходе
  `seen = 0`. По нему аддон показывает «офлайн».
- Сверка с коллекцией (`CollectionSync`) — когда аддон обновил снимок коллекции, или по пункту меню.
- После запуска с Windows (`--autostart`) — пауза 15 с и «тихие» 3 мин без уведомлений.

## Установка (`Installer.cs`)

Запуск из «Загрузок», с рабочего стола или из временной папки архива → «Установить Mount Sheet Sync?»:
«Да» — копия в `%LOCALAPPDATA%\Programs\MountSheetSync`, ярлык в «Пуск», запись в «Установленных приложениях»
(HKCU Uninstall, `--uninstall`), запуск оттуда; «Нет» — работа на месте, запоминается (`installDeclined`);
«Отмена» — выход. Удаление спрашивает, стереть ли и настройки.

## Обновления (`Updater.cs`)

- Через 1 мин после запуска и раз в сутки: `api.github.com/repos/Zlodyaga/mount-sheet-sync/releases/latest`;
  с галочкой «пробные версии» (`testVersions`) — список `/releases`, самый новый, включая пре-релизы.
- Сравнение как semver: `2.8.0-alpha1 < alpha2 < beta1 < 2.8.0` (`IsNewer`, `Stage`). Своя версия —
  `Program.FullVersion` = `Version` + `-Prerelease` (суффикс вписывает release.yml для тегов `v…-alphaN/-betaN`).
- Ставится только по щелчку: архив `MountSheetSync-<версия>.zip`, SHA-256 из `digest` выпуска (без него — отказ),
  exe → `.old` и подмена, перезапуск `--wait-pid … --updated-from …`. Подписанный exe — только тем же издателем.
- Аддон обновляется вместе, только если в его папке есть `installed-from-archive.txt` (ставили из архива);
  `SheetData.lua` и `Program.lua` переносятся. Аддон из CurseForge не трогается.

## Файлы (`%APPDATA%\MountSheetSync`, или `--data <папка>`)

`settings.json` (ключи: `mode`, `spreadsheetId`, `spreadsheetTitle`, `spreadsheetUrl`, `webAppUrl`, `secret`,
`wowPath`, `notifications`, `checkUpdates`, `testVersions`, `updateNotified`, `installDeclined`, `language`,
`pollSeconds`, `retrySeconds`), `google-token.dat`, `sent-ids*.txt`, `state.json` (последняя отправка и результат, «Последние события», о чём уже напоминали),
`sync.log` (по-русски при русском языке, иначе по-английски).

## Командная строка

`--once` (одна синхронизация и выход), `--test`, `--autostart`, `--google-login`, `--create-sheet [название]`,
`--sheet-lang <код>`, `--add-chars`, `--set-chars <json>`, `--sync-collection`, `--install`, `--uninstall [--yes]`,
`--check-update`, `--update`, `--data <папка>`; служебные: `--wait-instance`, `--wait-pid`, `--updated-from`.
Один экземпляр на пользователя (`Local\MountSheetSync.*`); второй запуск — уведомление «уже запущен» (или окно настроек, если программа не настроена). `--test` — проверка связи с таблицей.

## Языки программы

Тексты в коде — русские оригиналы, они же ключи (`Tr._`, `Tr.F`; журнал — `Tr.L`). Переводы:
`tools/i18n/ui*.txt` (5 языков) и `log.txt` (английский) → `program/i18n.json` (`tools/i18n/build.py`; `--check`
ищет непереведённое). Язык — как в Windows, если из шести, иначе английский; меню «Язык».
