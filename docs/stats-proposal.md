# Анонимная статистика: варианты для обсуждения

Черновик к разделу «Анонимная статистика» в `docs/TODO.md` (12.11.2026). Ничего из этого не сделано: сначала решения
пользователя по пунктам «Решить».

## Что уже решено

- Только с согласия: окно при первом запуске; закрыли без ответа — отказ. В первом выпуске с этой функцией окно один раз
  увидят и нынешние пользователи. Дальше — переключатель в настройках программы.
- Ничего из Google-таблиц, никаких имён персонажей, серверов, BattleTag, почты.

## Что отправлять (предложение)

Одно сообщение не чаще раза в сутки, при запуске программы, меньше 1 КБ:

| Поле | Пример | Зачем |
| --- | --- | --- |
| версия программы и аддона | 2.10.1 / 3.0.6 | кто не обновился, можно ли убирать старое |
| Windows (только старшая версия) | 10 / 11 | на чём проверять |
| язык программы и игры | ru / deDE | какие переводы важны |
| режим | на компьютере / Google-таблица | что развивать |
| число персонажей, вилкой | 1, 2–5, 6–10, 11+ | на какие размеры рассчитывать окно |
| счётчики аддона за сутки | открытий вкладок «Осталось» / «Попытки» / «Журнал», Ctrl + щелчков, ручных отметок | чем пользуются, а чем нет |
| есть ли Mapzeroth | да / нет | нужна ли своя схема порталов |

Счётчики считает аддон (в своих сохранениях, только числа), программа читает их вместе с остальным.

## Решить

1. **Номер установки.** (а) Без номера: видно только «сколько сообщений в день», то есть примерное число активных.
   (б) Случайный номер, созданный на компьютере: видно удержание («вернулся ли через неделю»), но это уже идентификатор —
   его надо описать в политике. *Предложение: (а) для начала.*
2. **Куда отправлять.**
   - Apps Script (веб-приложение) → своя Google-таблица. Бесплатно, знакомо, данные сразу в таблице. Google видит IP отправителя.
   - Cloudflare Worker → своя база (D1). Бесплатный уровень с запасом, IP наш код не хранит. Нужен аккаунт Cloudflare.
   - Готовый сервис (PostHog и т. п.). Быстро, но данные у третьей стороны — её надо назвать в политике.

   *Предложение: Apps Script — меньше всего нового.*
3. **Счётчики аддона**: брать все из таблицы выше или только версии и режим для первого раза.
4. **Показывать ли игроку, что уходит**: строка «Что отправляется» в настройках с точным текстом последнего сообщения.
   *Предложение: да — это снимает вопросы.*

## Решения пользователя (14.11.2026)

1. Номер установки — **да**, случайный, созданный на компьютере; описать в политике конфиденциальности.
2. Приёмник — **Apps Script** → Google-таблица пользователя.

4. Показывать игроку, что уходит, — **да** (точный текст последнего сообщения в настройках).

## Черновик абзаца для политики конфиденциальности (не опубликован)

**Анонимная статистика (только с вашего согласия).** При первом запуске программа спрашивает, можно ли отправлять автору
анонимную статистику. Если вы отказались, ничего не отправляется. Если согласились, программа раз в сутки отправляет одно
сообщение: версии программы, аддона и Windows (только «10» или «11»), язык программы и игры, где хранятся данные (на
компьютере или в Google-таблице), число персонажей вилкой (1, 2–5, 6–10, 11+), установлен ли аддон Mapzeroth, сколько раз
за день открывали окно и вкладки аддона, ставили метки и отмечали убийства вручную, и случайный номер установки.

Номер установки создаётся на вашем компьютере и не связан ни с вашим аккаунтом, ни с персонажами; по нему видно только,
что сообщения пришли от одной и той же установки. В сообщении нет имён персонажей, серверов, BattleTag, почты и ничего из
вашего списка или Google-таблицы. IP-адрес мы не сохраняем.

Сообщения принимает скрипт Google Apps Script автора и записывает в Google-таблицу автора; Google как поставщик услуги
обрабатывает запрос по своим правилам. Записи хранятся 12 месяцев, потом удаляются автоматически. Точный текст
сообщения показывает пункт «Что отправляется…» в меню значка. Выключить статистику можно там же в любой момент: номер
установки при этом стирается, а при повторном включении создаётся новый. Чтобы удалить уже отправленные записи, напишите
автору и назовите номер установки из «Что отправляется…».
